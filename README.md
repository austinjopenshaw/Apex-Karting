# 🏁 Apex — Kart Racing Companion

A concept + interactive prototype for a kart racing app (iOS & Android) aimed at
grassroots / club racers — built around a **parent and child racing together
under one account.**

## 📱 See it on your phone

Open **`index.html`** in any mobile browser. It's a single self-contained file —
no install, no build step. On a phone it runs fullscreen like a real app; on a
desktop it shows inside a phone frame.

> Live demo (once GitHub Pages is enabled): the prototype is served from this repo.

### What you can do in the prototype
- Tap through all five sections from the bottom tab bar
- **Use the lap timer** — tap *Start*, hit *+ Lap*, watch the live delta vs. your best
- **Switch drivers** (top-right avatar → Mike / Tyler) — every stat, kart, and PB updates
- **Open a session** to see lap-by-lap times, the setup that was run, and notes

## MVP at a glance
1. ⏱️ **Lap Timer** — big, trackside-friendly, GPS auto-lap, live delta
2. 📋 **Session Log** — track, weather, full lap times, notes, auto-saved
3. 🔧 **Garage** — karts + setup sheets tied to every session
4. 📈 **Insights** — best-lap trend, PBs per track, consistency
5. 👥 **Multi-driver account** — the whole family, one login
